# Landing Page Builder — דף נחיתה מקצועי בעברית

סקיל לבניית דפי נחיתה מקצועיים בעברית RTL, מבוסס על עקרונות CRO, פסיכולוגיה שיווקית וקופירייטינג להמרה.

---

## 🔴 שלב 0 — לפני שמתחילים (חובה!)

### א. לוגו
- אם ניתנה כתובת אתר של הלקוח → **לגשת לאתר ולחפש את הלוגו**
- אם נמצא לוגו → לשים בנאב ובפוטר
- אם **לא** נמצא לוגו → **לבקש מהלקוח לוגו לפני הבנייה**
- **אין להמשיך ללא טיפול בנושא הלוגו**

### ב. שאלות חובה לפני בנייה
תמיד לשאול לפחות:
1. "יש משהו שאתה רוצה להדגיש במיוחד בדף?"
2. "יש לך תמונות / סרטונים / חומרים שתרצה שנשלב?"
3. "מה המטרה העיקרית של הדף?" (רכישה / פנייה / הרשמה / הצטרפות)

**לאחר שהלקוח עונה — רק אז מתחילים לבנות.**

### ג. שילוב חומרים שהלקוח מספק
- סרטון מוצר → להטמיע בסקשן ייעודי עם כותרת וטקסט הסבר
- תמונת מוצר → לשלב ב-Hero או סקשן מוצר עם תיאור תכונות
- רשימת יתרונות → לבנות סקשן "למה לבחור בנו"
- כל חומר שהלקוח מספק → למצוא לו מקום הגיוני בדף

## 🔴 שלב 2 — מבנה דף נחיתה (AIDA + CRO)

### 1. NAV — ניווט קבוע
- לוגו בצד ימין
- קישורים לסקשנים + CTA בולט (WhatsApp / טופס)
- Sticky לראש הדף בגלילה
- `background: transparent` → `rgba(...)` עם `backdrop-filter: blur` בגלילה

### 2. HERO — לכידת תשומת לב (Attention)
- **כותרת ראשית**: תועלת ברורה תוך 5 שניות
  - פורמולה: `"{תוצאה רצויה} ללא {כאב}"`
  - חייב להיות ספציפי (מספרים, זמנים, תוצאות)
- **כותרת משנה**: הרחבה קצרה, פירוט היתרון
- **CTA ראשי אחד בלבד** — פועל חזק: קבל / שלח / התחל / הזמן
  - ✅ "שלח הודעה ב-WhatsApp" / "קבל הצעת מחיר עכשיו"
  - ❌ "לחץ כאן" / "ברוכים הבאים" / "צור קשר"
- תמונה / סרטון / אנימציה שמחזקת את המסר (אם הלקוח סיפק — לשלב)

### 3. SOCIAL PROOF מיידי
- לוגואים / "כפי שפורסם ב..." / ספרות מרשימות
- ממוקם מיד מתחת ל-Hero

### 4. PROBLEM / PAIN (Interest)
- "אתה מרגיש ש...?" — שפת הלקוח
- להראות הבנה של הכאב לפני הצגת הפתרון

### 5. SOLUTION / BENEFITS (Desire)
- **תועלות, לא פיצ'רים**: מה הלקוח *מקבל*, לא מה המוצר *עושה*
- 3–5 יתרונות עם אייקונים
- אם יש סרטון מוצר → לשלב כאן עם הסבר

### 6. HOW IT WORKS
- 3–4 שלבים פשוטים: "כך זה עובד"
- ממחיש שהתחלה קלה (מפחית הפעלה ראשונית)

### 7. TESTIMONIALS — קרוסלה JS
- **מינימום 10 המלצות** ספציפיות ומיוחסות
- **3 כרטיסים נראים בו-זמנית**
- כרטיס אחד נכנס מצד אחד ויוצא מהצד השני (Elementor-style)
- **JS עם infinite loop** (clones לפני ואחרי) — לא CSS animation
- חצי ניווט + נקודות dots + autoplay 4s + עצירה ב-hover

### 8. FAQ — שאלות ותשובות
- **מינימום 10 שאלות**
- **2 עמודות**: 5 שאלות בעמודה ימנית, 5 בעמודה שמאלית
- Accordion עם אנימציה
- HTML: שתי `div` נפרדות בתוך `grid: 1fr 1fr`
- לענות על: מחיר, התאמה, קושי, "מה אם לא יעבוד?"

### 9. CTA SECTION סופי (Action)
- חזרה על ה-CTA הראשי עם ניסוח שונה
- Risk Reversal: ערובה / "ללא התחייבות" / "שיחה חינמית"
- דחיפות: "מקומות מוגבלים" / "השאירו פרטים עוד היום"

### 10. FOOTER
- לוגו + תיאור קצר + סושיאל
- קישורי ניווט
- פרטי קשר (כתובת, טלפון, WhatsApp)

### 11. כפתור WhatsApp צף
- פינה שמאל תחתונה, תמיד
- אנימציית pulse

## 🔴 שלב 3 — פסיכולוגיה שיווקית (חובה ליישם)

| עיקרון | יישום |
|--------|-------|
| **Social Proof** | המלצות + לוגואים + מספרים ("500+ לקוחות") |
| **Authority** | תעודות / ניסיון / "כפי שפורסם ב..." |
| **Scarcity** | "מקומות מוגבלים" / תאריך — רק אם אמיתי |
| **Loss Aversion** | הדגש מה הם *מפסידים* בלי המוצר / שירות |
| **Reciprocity** | ערך חינמי תחילה (שיחה / מדריך / הצעה) |
| **Anchoring** | הצג מחיר גבוה קודם, אז את המחיר שלך |
| **Present Bias** | תועלות *מיידיות* ("חסוך זמן כבר היום") |
| **Hick's Law** | CTA אחד בלבד בכל סקשן |
| **Risk Reversal** | ערובה / "ללא התחייבות" ליד כל CTA |
| **AIDA** | סדר הדף: תשומת לב → עניין → רצון → פעולה |

## 🔴 שלב 4 — כללי קופירייטינג

- **תועלות > פיצ'רים**: "תחסוך 3 שעות" לא "מערכת אוטומציה מתקדמת"
- **ספציפיות > מעורפל**: "150 לקוחות" לא "הרבה לקוחות"
- **שפת הלקוח**: מילים שהקהל עצמו ישתמש
- **פועל חזק ב-CTA**: קבל / שלח / התחל / הזמן — לא "לחץ כאן"
- **כותרת ראשית**: תוצאה ברורה תוך 5 שניות

## 🔴 שלב 5 — כללי עיצוב וטכנולוגיה

- **Mobile-first**: מושלם בנייד
- **RTL מלא**: `dir="rtl"`, `text-align: right`
- **Sticky nav** עם שינוי צבע בגלילה
- **CSS Variables** לכל הצבעים
- **IntersectionObserver** להצגת אלמנטים בגלילה (`.reveal`)
- **גודל טקסט**: מינימום 16px, line-height 1.6–1.8
- **אנימציות**: 150–300ms, `transform`/`opacity` בלבד
- **CTA אחד ראשי** בכל חלק
- **WhatsApp float**: תמיד, עם pulse animation
